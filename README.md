# 학생명단 관리 시스템

**초등학교** 학생명단을 한 곳에서 관리하는 Windows 프로그램입니다.
학생정보를 한 번만 등록하면 검색·전입·전출·형제 탐색·주소 분류·통계·진급·명단 생성을 프로그램이 처리합니다.

> 자료는 **이 컴퓨터 안에만** 저장됩니다. 외부 서버나 AI 서비스로 보내지 않습니다.

두 가지 원칙으로 만듭니다.

- 학생정보는 한 번만 입력하고, 필요한 명단은 프로그램이 만든다.
- 원본 데이터는 보존하고, 시스템이 정리한 값을 따로 둔다.

설계와 진행 계획은 [docs/01-설계안.md](docs/01-설계안.md)에 있습니다.

---

## 지금 할 수 있는 것

- **학생 등록·수정** — 학년/반/번호 · 이름 · 성별 · 생년월일 · 주소 · 보호자 · 비고.
  반 이름은 `1` 도 `가람` 도 됩니다.
- **생년월일 정규화** — `170315` `17.03.15.` `17-03-15` `2017.03.15` 을 모두 같은 날짜로 읽고
  화면에는 `17.03.15.` 로 보여 줍니다. 달력에 없는 날짜는 **고치지 않고** 원본을 그대로 둔 채
  확인 필요로 표시합니다.
- **연락처 부분 검색** — `010-1234-5678` 을 `1234` 로도 `5678` 로도 찾습니다.
- **학생명단** — 학년·반·상태로 추리고, 검색 한 칸에서 이름·연락처·주소·번호를 함께 찾습니다.
  항목별로 따로 찾고 싶으면 [상세 검색]을 엽니다.
- **확인 필요** — 빠진 값이 있어도 등록을 막지 않고 표시만 남깁니다.
  값을 채워 저장하면 표시가 저절로 사라집니다.
- **학적 이력** — 학년도별 학적과 이동 기록(등록·전입·전출·진급·졸업)을 학생마다 보관합니다.
  지난 학년도 기록은 덮어쓰지 않습니다.
- **엑셀 명단 가져오기** — 파일을 고르면 열 이름을 알아서 짝지어 줍니다(성명·학급·출석번호 등).
  **저장하기 전에** 무엇이 새로 들어가고 무엇이 어떻게 바뀌는지 보여 줍니다.
  같은 파일을 다시 넣어도 학생이 두 벌로 쌓이지 않고, 엑셀 빈칸이 기존 값을 지우지 않습니다.

## 만드는 방법 (개발)

### 필요한 것

- [Node.js](https://nodejs.org) 20 이상
- [Rust](https://rustup.rs)
- Visual Studio Build Tools (C++ 데스크톱 개발)

### 실행

```bash
npm install
npm run app
```

### 실제 자료를 건드리지 않고 연습하기

```bash
npm run app:sandbox
```

자료를 `%APPDATA%\kr.school.studentroster.sandbox\` 에 따로 만들므로
실제 자료(`kr.school.studentroster`)는 손대지 않습니다. 창 제목에 **연습용**이라고 나옵니다.

### 연습용 자료 채우기

실제 학교 규모에서 화면을 확인할 때 씁니다. 생년월일 오타 · 빈 연락처 · 반 미정이
일부러 섞여 있어 '확인 필요' 흐름까지 볼 수 있습니다.

```bash
npm run seed
```

`npm run seed -- 300` 처럼 인원을 정할 수 있고, `npm run seed -- --reset` 은
연습용 학생을 모두 지우고 다시 채웁니다. 넣은 뒤 앱에서
**설정 → 자료 점검 → 확인 필요 다시 계산**을 한 번 누르면 표시가 만들어집니다.

> 연습용 폴더에만 씁니다. 실제 자료는 건드리지 않습니다.

### 가져오기 시험용 엑셀 만들기

```bash
npm run sample
```

제목 줄 · 다른 열 이름 · 숫자 칸 생년월일 · 앞자리 0이 빠진 연락처가 섞인 1,200명짜리 파일을
`scratch/` 에 만듭니다. 학교에서 실제로 오는 파일과 비슷하게 일부러 지저분합니다.

```bash
npm run sample -- 1200 "scratch/수정본.xlsx" --changed
```

연락처를 바꾼 판을 만들어 **다시 가져오기**(기존 학생 갱신)를 시험할 수 있습니다.

### 검사

```bash
npm run build           # 타입 검사 + 화면 빌드
npm run check:model     # 화면 쪽 순수 함수 검사 (표시 형식·상태 배지)
cd src-tauri && cargo test --lib   # 서버 테스트 (정규화·검색·확인 필요)
```

### 구조

```
src/                 React 화면
  components/        AppShell(사이드바) · ui(Page/Card/Table/Drawer/Badge …)
  features/          화면별 덩어리 — student/ (등록 폼 · 상세 Drawer)
  ipc/               Rust 명령 호출 래퍼 (Rust commands/ 와 1:1)
  lib/               화면 쪽 순수 함수 (표시 형식 · 학년도)
  pages/             화면
src-tauri/
  migrations/        SQL 마이그레이션 (번호순, 배포 후 수정 금지)
  src/commands/      Tauri 명령 (입력 검증만)
  src/repo/          SQL (저장소 계층)
  src/domain/        순수 계산 규칙 (생년월일 · 연락처 · 반 정렬 · 조사 …)
  src/import/        엑셀 가져오기 (읽기 · 짝짓기 · 분석 · 적용)
  src/job.rs         오래 걸리는 작업의 진행 상황 알림 (job://progress)
  src/db/            연결 · 마이그레이션 러너 · 백업
docs/                설계안
scripts/             아이콘 원본 · 버전 맞추기 · 연습용 자료 · 시험용 엑셀
```

규칙이 있는 계산은 모두 `src-tauri/src/domain` 에 두고 단위 테스트를 붙입니다.
화면은 보여 주기와 사용자 선택만 맡고, 저장되는 값은 언제나 Rust 가 만듭니다.

### 버전 올리기

```bash
npm run version:set 0.2.0
```

`package.json` · `tauri.conf.json` · `Cargo.toml` 세 곳을 한 번에 맞춥니다.

### 앱 아이콘

원본은 `scripts/appicon.png` 입니다. 바꿀 때는 그 파일을 갈아 끼우고:

```bash
npx tauri icon scripts/appicon.png
```

Windows 만 만들므로 생성된 `src-tauri/icons/android`, `ios` 폴더는 지웁니다.
