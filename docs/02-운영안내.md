# 운영 안내 — 설치 · 백업 · 복원 · 업데이트

학생 자료를 실제로 넣고 쓰는 분을 위한 문서입니다. 개발 설명은
[01-설계안.md](01-설계안.md) 에 있습니다.

---

## 1. 설치

1. 릴리스 페이지에서 `student-roster_0.1.0_x64-setup.exe` 를 내려받습니다.
2. 실행합니다. **관리자 권한이 필요 없습니다.**
   - Windows가 "PC를 보호했습니다" 창을 띄우면 **추가 정보 → 실행** 을 누르세요.
     코드 서명 인증서가 없는 프로그램은 모두 이렇게 나옵니다.
3. 설치가 끝나면 시작 메뉴에 **학생명단 관리 시스템** 이 생깁니다.

프로그램은 `%LOCALAPPDATA%\학생명단 관리 시스템\` 에 설치됩니다.
**학생 자료는 여기에 들어 있지 않습니다** — 아래 2번을 보세요.

---

## 2. 학생 자료는 어디에 있나요

```
%APPDATA%\kr.school.studentroster\
  studentroster.db        학생 자료 (이 파일 하나에 모두 들어 있습니다)
  backups\                백업 파일
```

탐색기 주소창에 `%APPDATA%\kr.school.studentroster` 를 붙여 넣으면 바로 열립니다.
프로그램 안에서는 **설정 → 자료 위치 → [자료 폴더 열기]** 로도 열 수 있습니다.

- 자료는 **이 컴퓨터 안에만** 있습니다. 외부 서버나 AI 서비스로 보내지 않습니다.
- **설치 폴더와 자료 폴더가 다릅니다.** 프로그램을 업데이트하거나, 지웠다가 다시
  깔아도 자료는 그대로 남습니다.
- 학생 개인정보가 들어 있는 파일이므로 **이 PC의 Windows 계정에 암호를 걸고**,
  가능하면 BitLocker(드라이브 암호화)를 켜 두세요.

## 3. 백업

### 저절로 만들어지는 백업

프로그램을 연 날마다 **하루에 한 번** 자동으로 백업합니다. 같은 날 여러 번 열어도
하나만 만듭니다. 자동 백업은 **최근 30개**까지 두고 오래된 것부터 정리합니다.

자료에 문제가 있는 것으로 확인되면 **자동 백업을 만들지 않습니다.**
손상된 자료로 뜬 백업이 멀쩡한 지난 백업을 밀어내면 되돌릴 곳이 사라지기 때문입니다.

### 직접 만드는 백업

**설정 → 백업 → [지금 백업]** 을 누르면 그 자리에서 만듭니다. 큰 작업(엑셀 가져오기,
학년도 전환) 전에 한 번 눌러 두면 마음이 놓입니다.

직접 만든 백업과 **학년도 전환 전·복원 전** 백업은 자동 정리 대상이 아닙니다.
지우려면 [백업 관리] 에서 직접 지워야 합니다.

### 백업 파일의 종류

| 이름 | 언제 만들어지나 | 자동 정리 |
|---|---|---|
| `auto_…` | 하루 한 번, 프로그램을 열 때 | ○ (최근 30개) |
| `manual_…` | [지금 백업] 을 눌렀을 때 | ✕ |
| `before_year_transition_…` | 학년도 전환 직전 | ✕ |
| `before_restore_…` | 복원 직전 | ✕ |
| `before_migration_…` | 자료 구조가 바뀌기 직전 | ✕ |

### 백업은 만든 뒤 확인합니다

파일을 만들었다고 끝내지 않고, 그 파일을 다시 열어 **자료가 성한지
(`integrity_check`)와 이 프로그램의 자료 구조가 맞는지**를 확인합니다.
확인에 실패한 파일은 지우고 알려 드립니다. 목록에도 `정상` / `확인 실패` 로 나옵니다.

### 다른 곳에 옮겨 두기

**설정 → 백업 → [백업 폴더 열기]** 로 폴더를 열고 파일을 USB나 다른 컴퓨터로
복사해 두세요. 컴퓨터가 고장 나면 이 폴더째 사라집니다.

> ⚠️ **백업 파일에는 학생 개인정보가 그대로 들어 있습니다.** 옮겨 둔 저장장치의
> 보관에 주의해 주세요.

## 4. 복원 (백업으로 되돌리기)

**설정 → 백업에서 복원** 에서 합니다. 백업 폴더에 있는 파일뿐 아니라 USB 등에
보관해 둔 `.db` 파일도 고를 수 있습니다.

되돌리는 차례는 이렇습니다.

1. 고른 파일을 **먼저 열어 봅니다** — 성한 SQLite 파일인지, 이 프로그램의 자료인지,
   이 버전이 읽을 수 있는 구조인지. 하나라도 어긋나면 **지금 자료를 건드리지 않고**
   무엇이 문제인지 알려 드립니다.
2. 파일을 프로그램 옆에 놓아 둡니다. **이때까지도 지금 자료는 그대로입니다.**
3. [프로그램 종료] 를 누르고 다시 켜면, 자료 파일을 열기 **전에** 갈아 끼웁니다.
4. 갈아 끼우기 직전에 지금 자료를 `before_restore_…` 로 한 번 더 백업합니다.
   되돌린 자료가 생각과 달랐다면 **그 파일로 다시 돌아올 수 있습니다.**

> 프로그램이 스스로 다시 켜지지 않는 까닭: 자료 파일을 갈아 끼우는 도중에 두 개의
> 프로그램이 같은 파일을 보는 일을 막기 위해서입니다. 사람이 다시 켜는 편이 안전합니다.

되돌리기를 준비해 두었다가 마음이 바뀌면 [되돌리기 취소] 를 누르면 됩니다.

## 5. 업데이트

**설정 → 프로그램 업데이트 → [업데이트 확인]** 을 누르면 새 버전이 있는지 알아봅니다.
하루에 한 번은 저절로 확인해서, 새 버전이 있으면 화면 위에 한 줄로 알려 드립니다.

- **확인만 하고 설치하지 않습니다.** [업데이트] 를 직접 눌러야 시작합니다.
- 내려받은 파일은 **만든 사람의 서명을 확인한 뒤에만** 설치합니다.
- 설치가 끝나면 프로그램이 저절로 다시 켜집니다. 혹시 켜지지 않으면 시작 메뉴에서
  다시 실행해 주세요.
- **인터넷에 연결되어 있지 않아도** 학생명단 기능은 모두 그대로 쓸 수 있습니다.
  업데이트 확인에 실패해도 프로그램 사용에는 아무 영향이 없습니다.
- 업데이트는 프로그램 파일만 바꿉니다. **학생 자료·설정·주소 규칙·형제 관계·
  전입/전출·졸업 기록은 그대로 남습니다.**

## 6. 프로그램을 지울 때

Windows **설정 → 앱** 에서 지우거나 설치 폴더의 `uninstall.exe` 를 실행합니다.

**학생 자료는 함께 지워지지 않습니다.** `%APPDATA%\kr.school.studentroster` 폴더는
그대로 남으므로, 프로그램을 다시 깔면 쓰던 자료가 그대로 열립니다.
자료까지 없애려면 그 폴더를 직접 지워야 합니다 — 지우기 전에 백업을 한 벌 옮겨 두세요.

## 7. 문제가 생겼을 때

| 증상 | 할 일 |
|---|---|
| 자료가 이상하다 | 화면 위에 빨간 줄로 알려 드립니다. **설정 → 백업 관리** 에서 `정상` 인 백업을 골라 되돌리세요 |
| 잘못 지웠다·잘못 바꿨다 | 같은 방법으로 그 전 백업으로 되돌리면 됩니다 |
| 프로그램이 열리지 않는다 | `%APPDATA%\kr.school.studentroster\backups` 의 최신 백업을 안전한 곳에 복사해 두고, 프로그램을 다시 설치해 보세요 |
| 컴퓨터를 바꾼다 | 새 컴퓨터에 설치한 뒤 **설정 → 백업에서 복원 → [다른 곳에 보관한 파일에서]** 로 옮겨 온 백업을 고르세요 |

백업 파일 위치: `%APPDATA%\kr.school.studentroster\backups`

---

## 8. 자료 구조 버전

자료 파일에는 구조 버전이 함께 저장됩니다(설정 화면의 **자료 구조 버전**).

- 새 버전 프로그램이 열면 필요한 만큼 구조를 올립니다. **올리기 직전에 자동으로
  백업**(`before_migration_…`)을 만듭니다.
- **더 최신 버전에서 만든 자료는 열지 않습니다.** 프로그램을 먼저 업데이트해 주세요.
  복원할 때도 마찬가지로 거절합니다 — 읽을 수 없는 자료를 억지로 열어 망가뜨리지
  않기 위해서입니다.
